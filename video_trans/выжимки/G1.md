- **Что можно сделать процессом в Битрикс24 (просто):**
  - Список «Конструкции/захватки объекта»: конструкция, работа по ЛСР, статус (РД есть → выполнено → дефект → принято технадзором → в КС-2 → оплачено). Фильтр «выполнено, но не в КС-2» — это деньги, которые можно предъявить.

  - Стадия «Запрос на изменение» в карточке объекта: изменение после утверждения сметы — только с расчётом и допсоглашением.

## Итог по группе

**Самые сильные идеи для нас (5–8):**
1. **Входной контроль и испытание бетона на ответственных заливках.** Кейс «Дом Газобетон»: проверенный завод привёз бетон вдвое ниже марки, пришлось сносить фундамент, примерно 1 млн по оценке спикера [53:56–54:52]. Чек-лист входного контроля с сертификатами и сроками [14bJWhugAz8, 2:02; 12:15].
2. **Цепочка «заявка → проверка остатков → КП → заказ → отгрузка → приход → списание»** с привязкой к объекту, виду работ и шифру ЛСР. Для модели «свои материалы» это прямая защита оборотки от перезакупа [14bJWhugAz8, 3:04–9:10].
3. **Статус по каждой конструкции/захватке** (выполнено / дефект / принято / в КС-2 / оплачено), чтобы видеть, что можно предъявить, и исключить двойное или пропущенное актирование [IYNO, 00:40:37–00:43:42].
4. **Задача не длиннее отчётного периода, недельное планирование по захваткам, прораб знает выработку бригады в деньгах** [IYNO, 01:04:54; 01:50:43; 02:12:48].
5. **Фиксированные точки и изменения только через оценку и допсоглашение.** Сверять объёмы договора с проектом до подписания (пример 13213 против 9569 м³) [IYNO, 00:28:00; 01:10:34].
6. **Давальческая модель:** согласованная ведомость потребности с датами и правило ответственности за недовоз. Без этого «спрос с тебя, если не хватило» [Дом Газобетон, 38:46–39:33].
7. **Регламенты картинками и видео плюс короткое еженедельное обучение** вместо толстых инструкций; база знаний у каждого отдела. Для штата из 6 человек это реально [Дом Газобетон, 50:03–52:54].
8. **Внедрять учёт по блоку за раз, начиная снизу** (сначала склад или приход, потом заявки) [14bJWhugAz8, 21:20–22:23]. Это совпадает с требованием «Битрикс24 максимально просто».

**Чего в этих видео не хватило для нас (3–5):**
1. Управления оборотными деньгами и кассовым разрывом: авансы, график платежей, сравнение моделей «свои материалы» и «материалы заказчика» по деньгам.
2. Специфики тендеров 44-ФЗ/223-ФЗ для малого подрядчика: обеспечение заявки и контракта, приёмка, исполнительная документация на мостах и подпорных стенах. Лекция по организации строительства устарела и нечитаема.
3. Работы с привлечёнными бригадами и арендной техникой по договору: расценки, акты, удержания, контроль машино-часов. В видео техника своя, а бригады штатные.
4. Учёта и отчётности по давальческим материалам (материалы заказчика): ведомость расхода, списание по нормам, возврат остатков.
5. Минимальной системы учёта для компании из 6 человек. Все показанные решения либо крупные (3000 и 100 рабочих мест, BIM), либо держатся на личном контроле собственника.
