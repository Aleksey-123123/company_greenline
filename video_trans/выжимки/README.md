# Выжимки из транскрипций видео

Первый проход: 38 уникальных видео разобраны в 8 групп (G1–G8), каждая
группа — отдельным заходом с чистым контекстом (правило §1 `CLAUDE.md`).
По каждому видео в выжимке: кто говорит, идеи с метками времени, что
можно сделать в Битрикс24, что спорно.

Сводные выводы — в `notes/0017`, `notes/0018`, `notes/0019`.

Выжимки — черновик первого прохода. Супервизор нашёл в них и в
заметках неточности (`супервизор-0009-0011.md`). Исправлены они в
заметках, а не здесь: при расхождении верна заметка.

**Дубли, не разбирались отдельно:**

  (тот же текст без меток времени, проверено в G3).
