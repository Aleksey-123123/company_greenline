# Как запустить бота на своём компьютере (Windows)

Бот работает, пока компьютер включён и открыто чёрное окно бота. Закрыли окно
или компьютер уснул — бот молчит, а сообщения прорабов ждут и придут, когда
бот снова запустится. Для пилота этого достаточно. Потом бота лучше перенести
на сервер.

Всего три этапа: **A** — скачать, **B** — попробовать без Google (10 минут),
**C** — подключить Google Таблицу (30 минут).

---

## A. Что скачать (один раз)

1. **Python** — программа, на которой написан бот.
   [python.org/downloads](https://www.python.org/downloads/) → жёлтая кнопка
   «Download Python». При установке **обязательно поставить галочку
   «Add python.exe to PATH»** внизу первого окна, затем «Install Now».
2. **Сам бот.** Скачать маленький архив (около 50 КБ):
   [greenline-bot.zip](https://github.com/Aleksey-123123/company_greenline/raw/claude/modest-thompson-2t6eug/greenline-bot.zip).
   Правой кнопкой по скачанному файлу → **«Извлечь всё…»** → например в
   `C:\greenline`. Внутри будет папка **`bot`** — дальше работаем только с ней.

   Если Windows пишет «Сжатая ZIP-папка имеет неверный формат» — файл
   скачался не до конца. Удалить его и скачать ещё раз, дождавшись конца
   загрузки. Размер должен быть около 50 КБ, а не 0 или 1 КБ.

Больше ничего ставить не нужно: остальное скрипт скачает сам.

---

## B. Пробный запуск без Google (10 минут)

1. **Создать бота в Telegram.** Открыть [@BotFather](https://t.me/BotFather) →
   `/newbot` → придумать имя (например «Гринлайн объекты») → придумать адрес,
   который заканчивается на `bot` (например `greenline_obj_bot`). BotFather
   пришлёт **токен** — строку вида `7412345678:AAH...`. Это пароль бота:
   никому не пересылать и в общий чат не писать.
2. В папке `bot` дважды кликнуть **`start.bat`**. Первый раз он 1–3 минуты
   ставит библиотеки, потом сам откроет Блокнот с файлом **`.env`**.
3. В Блокноте найти строку `BOT_TOKEN=` и вставить токен сразу после `=`,
   без пробелов: `BOT_TOKEN=7412345678:AAH...`. Сохранить (**Ctrl+S**) и
   закрыть Блокнот.
4. В чёрном окне появится «Бот запускается». Открыть своего бота в Telegram по
   адресу из шага 1 → «Запустить». Бот ответит и покажет кнопки.

В этом режиме (`STORAGE=memory`) любой, кто напишет боту, становится
директором, есть два демо-объекта, а после закрытия окна всё стирается.
Это чтобы понажимать кнопки и проверить, что бот вообще работает.

> **Где .env?** В папке `bot`, рядом с `start.bat`. Его создаёт `start.bat` из
> образца `.env.example`. В репозитории его нет специально: в нём токен бота,
> а репозиторий открыт для всех. Если Windows скрывает файлы с точкой —
> открыть `.env` можно так: Блокнот → Файл → Открыть → папка `bot` → внизу
> выбрать «Все файлы».

## C. Подключить Google Таблицу (30 минут, можно поручить помощнику)

1. **Таблица.** Создать пустую Google Таблицу «Гринлайн · бот». Скопировать её
   адрес из браузера целиком.
2. **Ключ Google** — нужен, чтобы бот мог писать в таблицу:
   1. [console.cloud.google.com](https://console.cloud.google.com) → войти той
      же почтой → вверху «Select a project» → **New project** → любое имя →
      Create.
   2. В поиске сверху набрать **Google Sheets API** → открыть → **Enable**.
   3. Меню слева → **IAM & Admin → Service Accounts → Create service account**
      → любое имя → Done.
   4. Нажать на созданный аккаунт → вкладка **Keys → Add key → Create new key →
      JSON → Create**. Скачается файл.
   5. Переименовать файл в **`service-account.json`** и положить в папку
      `bot\secrets`. Если Windows скрывает расширения, файл должен называться
      просто `service-account`, а не `service-account.json.json`.
   6. Скопировать e-mail этого аккаунта (вида `…@….iam.gserviceaccount.com`).
      В Google Таблице → **Настройки доступа** → вставить этот адрес → роль
      **Редактор** → Отправить.
3. **Настройки.** Закрыть окно бота. Открыть `.env` в Блокноте и поменять две
   строки:
   ```
   STORAGE=sheets
   SHEET_ID=<вставить адрес таблицы целиком>
   ```
   Сохранить.
4. Дважды кликнуть **`prepare-table.bat`**. Он создаст в таблице листы и
   **напечатает ссылку для директора** (`https://t.me/…?start=inv_…`).
   Скопировать её: в чёрном окне выделить мышью и нажать Enter.
5. Запустить **`start.bat`**. Директор открывает свою ссылку → «Запустить» —
   он в системе.
6. Помощник заполняет в таблице лист **«Объекты»**: ID (`О-01`, `О-02`) и
   название.
7. Директор в боте: **🔗 Пригласить** → роль → объекты → получает ссылку и
   пересылает человеку. Тот нажимает «Запустить» и сразу видит своё меню.

**Архив фото** (по желанию, потом): создать закрытый Telegram-канал, добавить
бота администратором, написать в канале `/chatid` и вписать ответ в `.env` →
`ARCHIVE_CHAT_ID=`. Перезапустить `start.bat`. Без архива фото тоже
принимаются, но в таблице вместо ссылок будут только служебные коды.

## Чтобы бот не засыпал

- Windows: **Параметры → Система → Питание → «Переводить в спящий режим» —
  Никогда** (при питании от сети).
- Не закрывать чёрное окно. Свернуть можно.
- После перезагрузки компьютера снова дважды кликнуть `start.bat`.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Python не найден» | переустановить Python с галочкой «Add python.exe to PATH» |
| «BOT_TOKEN не задан» | открыть `.env`, вставить токен после `BOT_TOKEN=`, сохранить |
| «Unauthorized» | токен вставлен с ошибкой или лишним пробелом — скопировать заново из @BotFather |
| «Для STORAGE=sheets нужны SHEET_ID…» | в `.env` не заполнен `SHEET_ID` |
| «No such file … service-account.json» | ключ не в папке `secrets` или называется иначе |
| «PERMISSION_DENIED» / 403 | таблица не расшарена на e-mail сервисного аккаунта (шаг C.2.6) |
| бот не отвечает | окно бота закрыто или компьютер уснул |
| окно `start.bat` мигнуло и закрылось | архив не распакован («Извлечь всё…») или старая версия файлов — скачать архив заново |

Mac или Linux: то же самое, только вместо `start.bat` — `./start.sh`, вместо
`prepare-table.bat` — `./prepare-table.sh` (в Терминале из папки `bot`).
