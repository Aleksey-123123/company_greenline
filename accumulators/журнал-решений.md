# Журнал решений

Накопитель. Дописывается **сверху** — свежие записи первыми.

Пишем сюда, когда решение принято или отменено. Смысл файла не в отчётности,
а в том, чтобы через полгода можно было понять, **почему** так решили, и
отличить ошибку решения от ошибки прогноза.

Формат записи:

```
## ГГГГ-ММ-ДД — краткая формулировка решения
**Кто решил:** имя
**Контекст:** что происходило, какие цифры были на руках
**Решение:** что делаем
**Основание:** ссылка на заметку / расчёт / строку данных
**Цена вопроса:** ___ ₽
**Что должно произойти, если решение верное:** проверяемый признак и дата
**Пересмотр:** дата, когда возвращаемся к решению
```

Последнее поле — самое важное. Решение без критерия проверки нельзя ни
подтвердить, ни опровергнуть, а значит, на нём нельзя научиться.
