# Реестр денег в работе

Накопитель по деньгам, которые **уже заработаны, но не получены**, и по
источникам быстрых денег. Основание — `notes/0002`, горизонт 0–30 дней.

Ведётся параллельно с `data/receivables.csv`: таблица — для расчёта
приоритета скриптом `models/collect_plan.py`, этот файл — для истории и
статусов.

## Правила ведения

- Строка появляется, когда источник **найден**, и закрывается, когда деньги
  **на счёте**. Не когда «обещали».
- Сумма всегда с основанием: акт, договор, письмо, выписка.
- Каждая строка имеет фамилию. Строка без ответственного — это не работа.
- Закрытые строки не удаляем, переносим в раздел «Закрыто». По ним потом
  видно, какие источники реально работают, а какие только выглядят.
