# 0010. Битрикс24 — каркас ведения проектов

**Дата:** 2026-09-29 · v2 — 2026-09-30 · **v3 (упрощённая) — 2026-09-30**
**Вопрос:** как устроить ведение объекта в Битрикс24, чтобы ничего не терять
и не усложнять
**Источник данных:** ответы директора на `notes/0009` (2026-09-29); 9 уточнений
директора (2026-09-30); замечание директора «возможно излишние функции»
(2026-09-30); сравнение со строительным софтом — `notes/0011`
**Связано:** `0009`, `0011`, `templates/чек-лист-нового-проекта.md`
**Статус:** черновик — шаг 2 из 3 (каркас). Супервизор не пройден.

---

## Короткий ответ

1. **Четыре сущности:** Объект · План-график · Заявка (деньги уходят) ·
   Поступление (деньги приходят).
2. **Одно правило против «всё срочно»:** до выхода на объект — график этапов
   и заявки по нему. Пока их нет, объект не переходит в «Работы».
3. **v3 — урезанная версия.** В ней оставлено только то, что директор назвал
   сам (счета, экономика, закуп, фин учёт, график + 9 уточнений). Всё, что
   добавлял я, вынесено в раздел «Позже, если заболит».

## Что убрано в v3 и почему

| Было в v2 | Стало | Почему |

## 1. Схема

```
  ОБЪЕКТ (сделка CRM): договор · порядок КС · удержание · БГ · бюджет
      │
      ├── ПЛАН-ГРАФИК (проект, Гант): этапы, параллельные тоже
      │         │
      │         ├──► ЗАЯВКИ        — деньги уходят  (бригадир подаёт по ссылке)
      │         └──► ПОСТУПЛЕНИЯ   — деньги приходят (КС, аванс, возвраты)
      │
      └── СВОДКА (пятница) → ПЛАНЁРКА (понедельник)
```

## 2. Объект — сделка в CRM

**Стадии:**

| # | Стадия | Что значит |
|---|---|---|
| 1 | Договор | подписан, заполнены условия |
| 2 | Подготовка | делаем график и заявки |
| 3 | Работы | **ворота 1:** есть график и заявки на первые 2 этапа |
| 4 | Сдано на объекте | работы закончены, КС ещё не все подписаны |
| 5 | Взаиморасчёты | КС подписаны, но есть неоплаченные счета — наши или нам |
| 6 | Гарантия | осталось вернуть удержание / БГ |
| 7 | Архив | **ворота 2:** нет открытых заявок и поступлений |

**Поля (14):**

| Поле | Значения |
|---|---|
| Вид работ | мост / стена / зернохранилище / ТЦ / металл / благоустройство / лестницы |
| Материалы | наши / заказчика |
| Сумма договора | ₽ |
| Срок окончания | дата |
| Порядок КС | по этапам / помесячно / в конце |
| Аванс | ₽ |
| Гарантийное удержание | % |
| БГ / обеспечение | текст: вид, сумма, до какой даты. Напоминание — задача за 30 дней до срока |
| Бюджет: материалы, подрядчики, техника, прочее | 4 поля, ₽ |
| Оплачено всего / остаток | ₽ — экономист по пятницам |

## 3. План-график — проект с Гантом

- Этапы — задачи с датами. Связь ставится, **только если этап ждёт
  предыдущий**. Без связи этапы идут параллельно (гранит ∥ опоры освещения).
- В каждом этапе последний пункт чек-листа — «площадка убрана, фото».
- Диск: `Договор и смета` · `Исполнительная и сертификаты` · `Фото` · `КС`.
- **Шаблон:** на старте один — под пилотный объект. Правит помощник, каждая
  правка одной строкой в описании шаблона (дата, что, почему). Идущие объекты
  правка не меняет.

## 4. Заявка — деньги уходят

**Откуда:** бригадир — веб-форма по ссылке с телефона (объект, что, сколько,
к какой дате, фото). Или помощник — по графику на старте объекта.

**Стадии:**

| # | Стадия | Кто |
|---|---|---|
| 1 | Новая | бригадир / помощник: найти поставщика, приложить счёт |
| 2 | На согласовании | директор |
| 3 | К оплате | бухгалтер. **Постоплата ждёт здесь своей даты** |
| 4 | Частично оплачено | бухгалтер |
| 5 | Оплачено | бухгалтер |
| 6 | Закрыто | помощник: **оплачено + поставлено + сертификаты (если нужны)** |
| — | Отклонено | директор |

**Поля (10):** объект · тип (материал / подрядчик / техника / прочее) · что
нужно · к какой дате · срочно (галочка) · сумма · оплачено · **безнал /
наличные** · **поставка: нет / частично / получено** · **нужны сертификаты:
да/нет** + файлы (счёт, сертификаты, накладная, чек).

Правило: заявку с «нужны сертификаты = да» нельзя закрыть без файла.

## 5. Поступление — деньги приходят

**Типы:** аванс · КС · возврат (удержания или обеспечения).

Создаются на старте по полю «Порядок КС»: по одному на этап, на месяц или
одно итоговое. Плюс одно «Возврат удержания», если удержание есть.

**Стадии:** Запланировано → Передано заказчику → Подписано → Оплачено.

**Поля (5):** объект · сумма КС · удержание · к получению · плановая дата денег.

## 6. Роли

| Кто | Что делает |
|---|---|
| Директор | согласует заявки, планёрка, читает сводку |
| Помощник (позже снабженец) | графики, заявки, поставка, сертификаты, этапы |
| Экономист | условия объекта, поступления, КС, пятничная сводка |
| Бухгалтер | оплаты — стадии 3–5 заявок и «Оплачено» у поступлений |
| Геодезист | разбивка, исполнительные, фото площадки |
| Бригадиры | только веб-форма, без доступа в Битрикс |

## 7. Ритм

- **Старт объекта:** график + заявки на этапы + поступления. Без этого не
  переходим в «Работы».
- **Понедельник, 30 минут:** по каждому объекту — отстаём ли по графику;
  какие заявки нужны на 2 недели; чистая ли площадка.
- **Пятница — сводка директору:**

| Блок | Откуда |
|---|---|
| Остаток бюджета | поля объекта |
| План-график | Гант |
| Нужно денег на 2 недели | заявки стадий 1–4 по дате, безнал и наличные отдельно |
| Придёт денег за 4 недели | поступления стадий 1–3 по плановой дате |

## 8. 1С и тариф

- **1С:** на старте без связи — бухгалтер отмечает оплаты вручную. Обмен —
  после обкатки, на тарифе, где он есть [?].
- **Тариф:** бесплатного не хватит: там ограничены роботы и нет интеграций
  ([helpdesk](https://helpdesk.bitrix24.ru/open/28721100/)). Настраиваем на
  15-дневном демо [?], затем берём минимальный тариф, где есть: смарт-процессы
  (2 шт.), CRM-форма, обязательные поля по стадиям, Гант со связями, обмен с 1С.
  Цены — нет данных.

## Позже, если заболит

Не настраиваем, пока нет конкретного случая. Если случай был — добавляем
одну вещь, а не всё сразу.

| Что | Когда добавлять |
|---|---|
| Тендеры и расчёты в воронке | когда начнём терять заявки или деньги в обеспечении заявок |
| Доп. работы без допсоглашения — отдельный учёт | первый случай, когда за доп. работы не заплатили |
| Замечания заказчика — отдельный реестр со сроками | ещё один штраф за замечание, которое было известно заранее |
| Реестр БГ вместо строки в объекте | больше 2 гарантий на одном объекте |
| Робот «срочно», робот-задача директору | директор пропускает заявки на согласовании |
| Шаблоны «Каркас» и «Благоустройство» | когда пойдёт объект этого вида |
| Зачёт аванса по каждому КС | когда кассовый прогноз разойдётся с фактом из-за аванса |
| Отчёт по давальческим материалам | первый объект, где заказчик его требует (`0007` H6) |
| Реестр договоров подряда | больше 3–4 платежей одному подрядчику на объект |
