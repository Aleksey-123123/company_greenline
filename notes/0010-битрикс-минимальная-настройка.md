# 0010. Битрикс24: минимальная настройка под нас

**Дата:** 2026-10-07
**Вопрос:** какие процессы из видео перенести в Битрикс24 сейчас, при
малом числе проектов и 6 сотрудниках, и что отложить до роста
**Источник:** `notes/0009`, выжимки `video_trans/выжимки/G1–G8.md`
**Связано:** отдельная работа по настройке Битрикс24 — эта заметка для
неё вход, а не замена
**Статус:** черновик до прохода супервизора

---

## Короткий ответ

1. **Сейчас — 5 вещей**, все на стандартных инструментах (сделки,
   задачи с чек-листами, группы, Диск). Ни одной интеграции.
2. **Через месяц**, если первые 5 живут, — ещё 4. **При росте** — всё
   остальное.
3. Правило отбора: процесс попадает в Битрикс, только если он
   **защищает деньги**. Красивые отчёты — потом.

## Принципы (из видео)

- «Лучше 10% сегодня, чем 100% через год» [BI Group 3:06].
- Сначала учёт факта, потом планы. Гант не обязателен [Иван 4:44, 27:08].
- Не автоматизировать хаос: сначала процесс описать словами
  [Круглый стол стр. 1496–1541].
- Прораб вносит минимум и с телефона. Его работа — строить
  [Круглый стол стр. 1560–1572; 1С-ERP 59:51].
- Коробка без доработок [Минстрой 28:31]. Для оборота до ~100 млн
  Битрикс24 достаточно [Иван 1:52].

**Наше правило (оценка):** прорабу — не больше 10 минут в день на
Битрикс. Если форма требует больше — форма плохая.

## Этап 1. Сейчас (до 2026-10-23)

### 1. Объект = сделка в воронке «Объекты»

Стадии:
`Договор подписан → Готов к старту → Работы → КС-2 выставлена →
Оплачено → Гарантия → Закрыт`

Поля (только эти):
- **Модель:** свои материалы / материалы заказчика
- **Канал:** тендер / частный
- сумма договора, аванс (% и дата), срок оплаты по договору
- гарантийное удержание (% и дата возврата)
- **Сделано, но не подписано, ₽** — обновляет экономист раз в неделю
- **Свои деньги в объекте, ₽** — обновляет бухгалтер раз в неделю

Зачем: два последних поля — это деньги в работе и «пирамида»
[1С-учёт 17:36; Сессия-2023 19:21]. Фильтр по ним ответит на вопрос
понедельничной планёрки из `0006`.

Переход в «Готов к старту» — только после чек-листа «готовность
фронта» (пункт 3).

### 2. Группа объекта (чат + Диск)

- Участники: директор, прораб, экономист, геодезист. Заказчика при
  желании позвать как внешнего участника.
- Диск, папки: `РД` · `ИД` · `Письма` · `КС` · `Сертификаты` · `Фото`.
- Правило прораба: каждый день фото и 2–3 строки «что сделали».
- Старую версию РД не удалять, а переносить в `РД/Архив` [ЛИС 3:04].

Это замена мессенджеру, а не новая система [Ремонтник стр. 1261–1297].

### 3. Шаблоны задач с чек-листами

Три шаблона, больше пока не нужно:

**«Допработа»** — самое важное:
- [ ] фото и объём (прораб)
- [ ] укрупнённый расчёт (экономист)
- [ ] письмо заказчику, исх. № (помощник)
- [ ] ДС подписано или письменное указание получено
- [ ] наряд бригаде

Задача закрывается только после ДС. Основание: [Сессия-2023 46:31;
НОТЕХ 1:23:48; 1С-учёт 26:24].

**«Скрытая работа / АОСР»:**
- [ ] исполнительная схема (геодезист)
- [ ] сертификаты на материал в папке, срок действия проверен
- [ ] АОСР подготовлен (прораб)
- [ ] подписан стройконтролем — подтверждает не прораб
- [ ] скан в `ИД`

Основание: [ИД 8:28–9:29, 1:22:58; Сессия-Росатом 1:22:16].

**«Готовность фронта»** (перед вызовом бригады или техники):
- [ ] доступ на площадку
- [ ] РД на эту работу есть
- [ ] материал на месте или дата поставки подтверждена
- [ ] техника подтверждена
- [ ] допуски и ППР

Основание: [Автобан 13:01; НОТЕХ 42:57].

### 4. Регулярная задача «Недельный факт» (прораб, пятница)

Пять строк:
- что сделано (объём по 3–5 ключевым работам)
- сколько людей было
- причина отставания: нет материала / нет фронта / нет РД / погода /
  бригада
- что нужно от офиса
- 3 фото

Основание: [BI Group 6:11–7:12; Автобан 21:19]. Норматив — 80% плана.

### 5. Регулярная задача «Деньги на 13 недель» (бухгалтер, понедельник)

Файл Excel на Диске, не поля в Битриксе. Строки: остаток, ожидаемые
поступления по договорам (аванс, этапы, возврат удержаний),
обязательные платежи. Итог — одна цифра из `0006`.

Основание: [1С-ERP 1:47:37; БИТ 10:40, 13:59; Круглый стол стр. 95–107].

## Этап 2. Через месяц, если этап 1 живёт (до 2026-11-30)

6. **Смарт-процесс «Заявка на материал»** — только для объектов
   «свои материалы». Стадии: `Заявка → Проверка остатков → Заказ →
   Привезли → Входной контроль`. Поля: объект, позиция ЛСР, кол-во,
   нужно к дате, флажок «сверх ведомости» → согласует директор
   [БИТ 40:16–45:25; Круглый стол стр. 1218–1228].
7. **Список «Ждём от заказчика»** по объекту: что, срок по договору,
   факт, исх. № письма. Просрочка → задача помощнику «письмо»
   [Плиев 00:10:29; Риски бюджета 00:19:55].
8. **Воронка «Тендеры и КП»** с полями: замороженные деньги, ₽ и мес.;
   снижение цены, %; модель; 3–5 допущений. Ниже порога снижения —
   только решение директора [Школа ГЗ 57:15; Автодор 1:00:20].
9. **Чек-лист «Приёмка бетона»** на каждую заливку: паспорт, образцы,
   фото, кто принял [Газобетон 53:56].

## Этап 3. При росте (3+ объекта одновременно или 2-й прораб)

- Справочник бригад: специализация, ставки, статус ИП/самозанятый,
  оценка после объекта [Владивосток; Под ключ 0:13].
- Выработка бригад по видам работ [Штейнбах 7:59].
- Бизнес-процесс «Заявка на оплату» с согласованием [БИТ 11:30].
- Смарт-процесс «Давальческие материалы»: приход, списание, остаток
  [Круглый стол стр. 962–975].
- Справочник удельных стоимостей по закрытым объектам
  [Due diligence 34:20].
- Реестр рисков объекта, 5 строк [BI Group 15:12].

## Чего не делать сейчас

- Интеграцию с 1С.
- Диаграмму Ганта и связи задач.
- Дашборды и отчёты (хватит фильтров по сделкам).
- Многоуровневые согласования.
- Учёт техники — она у нас арендная [БИТ 51:51].
