# 0016. Битрикс24 — настройка по шагам

**Дата:** 2026-10-05
**Вопрос:** что и в каком порядке нажимать, чтобы собрать каркас `0010` в
нашем портале
**Источник данных:** каркас `0010` (v6); скриншот портала от 2026-10-05
(бесплатный тариф, новый интерфейс: меню слева — Мессенджер, BitrixGPT, Лента,
Календарь, Документы, Доски, Диск, Почта, Проекты, Задачи, CRM, Онлайн-запись,
Складской учёт, Маркетинг, Сайты и Магазины, КЭДО + Госключ, Настройки)
**Связано:** `0010`, `0007` (H5, H11, H13, H14)
**Статус:** шаг 3 из 3 — настройка. Идём по шагам, после каждого — скриншот.

> Названия кнопок в Битриксе меняются от версии к версии. Если пункт назван
> иначе или его нет — присылайте скриншот, подскажу по месту. Ничего не
> удаляем, только скрываем: удалённое не вернуть.

## Шаг 0. Подготовка (на бесплатном тарифе)

**0.1. Часовой пояс.** Настройки → Настройки портала (или «Общие») →
часовой пояс **Новосибирск, UTC+7**. Иначе сроки задач и даты оплат будут
сдвинуты на 4 часа.

**0.2. Убрать лишнее из меню.** Пункты не удаляем — скрываем. Наведите на
пункт меню слева → три точки (или правый клик) → «Скрыть пункт» /
«Настроить меню».

| Оставить | Скрыть |
|---|---|
| Мессенджер, Задачи, Проекты, CRM, Диск, Календарь, Настройки | BitrixGPT, Лента, Документы, Доски, Почта, Онлайн-запись, Складской учёт, Маркетинг, Сайты и Магазины, КЭДО + Госключ |

«Сайты и Магазины» скрываем, но помним: там могут лежать **CRM-формы**
(шаг 7) — тогда временно вернём.

**0.3. Структура компании.** Сотрудники (или «Компания») → Структура
компании. Отделы: Руководство · Проекты · Снабжение · Экономика и бухгалтерия ·
Геодезия. Сотрудников пока **не приглашаем** — каждый приглашённый занимает
место на тарифе. Сейчас в портале уже двое: Виталий Демидов и Кристина
Безбородова — кто они по ролям? [?]

**0.4. Справочники — на бумаге или в Excel** (понадобятся на шагах 2–5):
1. Список действующих объектов: название, адрес, заказчик, сумма, сроки.
2. Статьи затрат — 4: материалы, подрядчики, техника, прочее. Экономист и
   бухгалтер подтверждают, что в их таблице и в 1С те же (правка 1 из v6).
3. Какой объект берём пилотным.
4. Этапы графика пилотного объекта (8–12), какие идут параллельно.

## Шаг 2. Воронка «Объекты»

**2.1.** CRM → Сделки → режим «Канбан» → настройка воронок (шестерёнка или
«Воронки и туннели»). Общую воронку **переименовать в «Объекты»**.

**2.2. Стадии** (лишние стандартные — переименовать или удалить, пока сделок нет):

| # | Стадия | Тип |
|---|---|---|
| 1 | Договор | в работе |
| 2 | Работы | в работе |
| 3 | Выполнено | в работе |
| 4 | Гарантия | в работе |
| 5 | Архив | успешная |
| — | Отказ | провальная |

**2.3. Поля карточки.** Открыть любую тестовую сделку → «Создать поле» (или
в блоке — «Настроить» → «Создать поле»). Поля:

| Блок | Поле | Тип поля |
|---|---|---|
| Договор | Вид работ | Список: мост / подпорная стена / зернохранилище / ТЦ / металлоконструкции / благоустройство / лестницы |
| | Адрес объекта | Строка (или Адрес) |
| | Материалы | Список: наши / заказчика |
| | Сумма договора | стандартное поле «Сумма» |
| | Начало работ | Дата |
| | Окончание по договору | Дата |
| | Прогноз окончания | Дата |
| | Текущий этап | Строка |
| | Порядок КС | Список: по этапам / помесячно / в конце |
| | Условия оплаты | Строка (например, «15 раб. дн. после подписания») |
| | Аванс | Деньги |
| | Удержание, % · Удержание, ₽ | Число · Деньги |
| | БГ / обеспечение / страховка | Строка · «Действует до» — Дата |
| | Гарантия на работы до | Дата |
| Бюджет (экономист) | Материалы · Подрядчики · Техника · Прочее | Деньги ×4 |
| Сводка | Оплачено · Предстоит · Счета на оплате | Деньги · Деньги · Строка |
| | Пометки | Строка («подписываем КС», «к оплате счетов …») |

**2.4. Вид карточки в канбане.** В канбане → настройки → «Поля в карточке
канбана»: Сумма, Текущий этап, Прогноз окончания, Гарантия до, Пометки.

**2.5. Обязательность.** Поле «Окончание по договору» и «Порядок КС» —
обязательные с стадии «Работы» (в настройках поля — «Обязательно на
стадиях») [?].

**Проверка:** создать тестовую сделку «ТЕСТ», провести её по всем стадиям,
прислать скриншот карточки и канбана.

## Шаг 3. Смарт-процесс «Заявки на закуп»

**3.1.** CRM → меню «Ещё» / «Смарт-процессы» → Создать. Название «Заявки на
закуп». Включить:
- Воронки и стадии;
- Привязка к **Сделкам** (родитель — объект);
- Сумма и валюта — даёт итоги по колонкам;
- Роботы и триггеры;
- Использование в CRM-формах [?];
- Файлы / Наблюдатели — если есть такие галочки.

**3.2. Стадии:** Новая · Согласование · К оплате · Частично оплачено ·
Оплачено · **Закрыто** (успешная) · Отклонено (провальная).

**3.3. Поля:**

| Поле | Тип |
|---|---|
| Объект | привязка к сделке (из 3.1) |
| Этап | Строка |
| Тип | Список: материал / подрядчик / техника / прочее |
| Что нужно | Строка (многострочная) |
| Нужно к | Дата |
| Срочно | Да/Нет |
| Поставщик | Строка (или привязка к компании CRM) |
| Откуда доставка | Строка |
| Наличие | Список: в наличии / под заказ |
| Срок производства, дн. | Число |
| Сумма счёта | Деньги |
| Оплачено | Деньги |
| **Сумма** (стандартное) | = остаток к оплате (для итогов колонок) |
| Способ оплаты | Список: безнал / наличные / бизнес-карта |
| Условия оплаты | Список: предоплата / частями / постоплата |
| Оплатить до | Дата |
| Поставка | Список: нет / частично / получено |
| Нужны сертификаты | Да/Нет |
| Файлы | Файл (множественное): счёт, сертификаты, УПД, чек |

**3.4. Роботы** (простые, по одному):
- на стадии «Согласование» — задача директору «Согласовать оплату»;
- на стадии «Оплачено» — изменить элемент: Сумма = Сумма счёта (чтобы в
  колонке «Оплачено» была полная сумма);
- «Сертификаты» и «Файлы» — обязательные на стадии «Закрыто», если
  «Нужны сертификаты = да» [? — условная обязательность может не
  поддерживаться; тогда — обязательны всегда на «Закрыто»].

**Проверка:** 3 тестовые заявки к тестовому объекту, провести одну через все
стадии, одну — «наличные» сразу в «Оплачено». Скриншот канбана с итогами.

## Шаг 4. Смарт-процесс «Поступления»

**4.1.** Создать так же: привязка к Сделкам, сумма и валюта, роботы.

**4.2. Стадии:** Запланировано · Передано заказчику · Подписано ·
**Оплачено** (успешная) · Отменено (провальная).

**4.3. Поля:** Объект (привязка) · Тип (аванс / КС / возврат) · Сумма КС
(деньги) · Удержание (деньги) · **Сумма** = к получению · Деньги к (дата) ·
Как передано (строка: «письмо № / дата») · Дата подписания (дата) · Скан
(файл).

**4.4. Робот:** на стадии «Передано заказчику» — через 10 дней задача РП
«Позвонить заказчику по КС»; через 15 дней — «Отправить письмо с вызовом на
приёмку» (правка 6 из v6).

## Шаг 5. График пилотного объекта

**5.1. Шаблон.** Задачи → Шаблоны → Создать шаблон «Объект — [вид работ]».
Подзадачи — этапы. В каждом этапе чек-лист:
- «ИД по этапу передана ПТО»;
- последний пункт — «Площадка убрана, фото в чате».

В этапе «Бетонирование» дополнительно: паспорт на каждую машину · образцы
отобраны · результат испытаний до нагрузки (правка 7).

**5.2. Проект.** Проекты → Создать проект «[объект]» → задачи из шаблона →
вкладка «Гант»: даты от срока договора назад, связи только где этап ждёт
предыдущий.

**5.3. Папки на Диске проекта:** «Договор и смета» (смета при подписании —
отдельным файлом) · «Исполнительная и сертификаты» · «Фото» · «КС».

**5.4.** В карточке сделки-объекта — ссылка на проект (поле или комментарий).

## Шаги 6–9 — после проверки шагов 2–5

Распишу подробно, когда пройдём первые: каждый следующий зависит от того, как
поведёт себя портал на предыдущем.

- **6. Чат объекта:** у проекта свой чат; РП добавляет директора, снабженца,
  геодезиста. Бригадир — внешний участник: проверяем «Коллабы» (`0007` H14).
- **7. Форма заявки:** CRM-форма с 5 полями (объект, этап, к дате, комментарий,
  фото/файл) → создаёт заявку в стадии «Новая» [?].
- **8. Права:** бухгалтер видит все заявки и поступления; снабженец — заявки;
  экономист — поля бюджета; РП — всё по своим объектам.
- **9. Отборы для сводки:** «Заплатить 2 / 4 недели», «Придёт 2 / 4 недели»,
  «Выполнено, КС не подписаны».
