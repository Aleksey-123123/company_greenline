# 0015. Пять роликов о стройке и ремонте — что берём

**Дата:** 2026-10-05
**Вопрос:** есть ли в пяти роликах что-то полезное для каркаса `0010`, не
усложняя его
**Источник данных:** `data/транскрипции-ролики/` — 5 файлов:
1 — подкаст с владельцем компании по ремонту квартир;
2 — демонстрация 1С:ERP + Управление строительной организацией;
3 — юрист о договоре подряда и приёмке работ;
4 — подкаст с владельцем компании, строящей загородные дома из газобетона;
5 — экскурсия по отделам компании, строящей деревянные дома.
**Связано:** `0010`, `0013`, `0014`
**Статус:** черновик. Супервизор не пройден.

---

## Короткий ответ

1. **Полезнее всех ролик юриста (3).** Если заказчик не подписывает КС,
   звонка мало — нужен порядок: письмо с вызовом на приёмку → требование
   письменного мотивированного отказа → односторонний акт. Это одна строка в
   правилах и одно поле в поступлении.
2. **Ещё три правила без новых функций:**
   - для бетона — паспорт на каждую машину и образцы на испытание (в чек-лист
     этапа «Бетонирование»);
   - крупная предоплата новому поставщику или подрядчику — только после
     проверки и частями;
   - объём в плановой заявке на закуп берём из сметы, а не со слов бригадира.
3. **Не берём:** 1С:ERP со всеми модулями (ролик 2), стоп-листы, лимиты ДДС,
   маркетинг и продажу заявок.

## Сверка с каркасом `0010`

| Тезис | У нас | Решение |
|---|---|---|
| 3. Отказ от подписания КС | РП звонит через 10 дней | **берём**: порядок на 10-й, 15-й, 20-й день (действие 1); в поступлении — поле «как передано»: письмо № / дата + скан |
| 3. Скрытые работы — отдельно, с сертификатами и документами о покупке | сертификаты в заявке; ИД по этапам (`0014`) | **подтверждает**. Документы из заявок на закуп и есть доказательная база для актов скрытых работ |
| 3. Кто даёт проект — в договоре | чек-лист «брать ли проект» | **берём одной строкой** в чек-лист нового проекта (действие 4) |
| 4. Бетон не той марки | пометка «нужны сертификаты» | **берём**: в шаблон этапа «Бетонирование» — паспорт на каждую машину, отбор образцов, результат испытаний до нагрузки; новый завод — проверить до первой поставки (действие 2) |
| 1. 70 % предоплаты мошенникам | директор согласует оплаты | **берём правилом**, без настройки: новому поставщику или подрядчику — предоплата частями, крупную — после проверки (действие 3) |
| 5. Объём материала — по проекту, а не на глаз | плановая заявка от РП, уточнение от бригадира | **берём правилом**: в плановой заявке объём — из сметы. Если бригадир просит больше — видно сразу. Отдельное поле не заводим |
| 1, 4. Чат на объект, предписания в чате | чат объекта, задачи из сообщений | **подтверждает** |
| 1. Хватит чата, CRM не нужна | Битрикс | **не меняем**. Ремонтнику хватает чата: платит клиент, деньги простые. У нас тендеры, КС, удержания, БГ и кассовый разрыв — это чат не показывает |
| 1, 4. Предел нагрузки: прораб — до 6 объектов | 3–6 объектов на одного РП | **учесть при найме**: 6 объектов — потолок для одного РП |
| 4. Регламент как комикс | регламент на 1–2 страницы (`0014`) | **берём**: со скриншотами экранов Битрикса; по возможности — короткие видео с экрана |

## Не берём

1С:ERP и УСО (ролик 2) — уровень крупных предприятий. Стоп-листы отгрузки,
лимиты ДДС, многоуровневое согласование, ведомости материалов из 3D-модели,
маркетинг, блог и продажа заявок — не про нас.
