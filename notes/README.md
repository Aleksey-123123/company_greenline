## Порядок чтения

**Если времени 5 минут:** `0002`, раздел «Короткий ответ».

**Если полчаса:** `0001` → `0002` → `0006`.

**Если разбираемся всерьёз:** по порядку, с запуском моделей на своих данных.

---

## Что делать дальше

1. Закрыть блок A и C в `0007` — это данные, без которых всё остальное
   остаётся оценкой.
2. Заполнить `data/projects.csv` и `data/receivables.csv`, запустить
   `models/cash_model.py` и `models/collect_plan.py`.
3. Прогнать `0002` через супервизора (`templates/промпт-супервизор.md`) —
   отдельным запросом, с чистым контекстом. До этого заметка — черновик.
4. Решения записать в `accumulators/журнал-решений.md`.

## Как завести новую заметку

Взять `templates/заметка.md` → назвать `NNNN-короткое-имя.md` со следующим
свободным номером → дописать строку в эту таблицу.
