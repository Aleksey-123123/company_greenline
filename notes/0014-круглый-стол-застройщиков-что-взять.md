# 0014. Круглый стол застройщиков — что берём

**Дата:** 2026-10-02
**Вопрос:** есть ли в выступлениях застройщиков что-то полезное для нашего
каркаса `0010`
**Источник данных:** `data/транскрипция-круглый-стол-застройщики.txt`
(автотранскрипция, 7 выступлений, ~2 250 строк; ниже ссылки на строки файла)
**Связано:** `0010`, `0013`
**Статус:** черновик. Супервизор не пройден.

---

## Короткий ответ

1. **Почти всё — для девелоперов с проектным финансированием и ERP за
   десятки миллионов.** Нам это не подходит.
2. **Берём три вещи, без новых разделов:**
   - исполнительная документация — **по ходу каждого этапа**, а не одним
     этапом в конце;
   - гарантийные замечания — задачами в проекте объекта, а повторяющиеся
     попадают в шаблон графика;
   - после согласования — **регламент на 1–2 страницы** из презентации,
     и директор лично держит правило «нет заявки — нет оплаты».
3. **Вне Битрикса, для финансов:** «чёрный бюджет» — проверить, переживёт ли
   компания падение выручки на 20–30 % и 50–70 %, и на сколько месяцев хватит
   подушки. Это к заметкам о деньгах (`0002`, `0003`), не к Битриксу.

## Сверка с каркасом `0010`

| Тезис | У нас | Решение |
|---|---|---|
| 3. ИД в конце — аврал | этап «Исполнительная» перед сдачей | **берём**: в чек-лист каждого этапа — пункт «ИД по этапу передана ПТО» (акты скрытых работ, схемы по меткам геодезиста, фото из чата). Финальный этап остаётся для комплектования |
| 2. Гарантийные замечания → улучшения | стадия «Гарантия», срок гарантии в карточке | **берём**: замечание заказчика по гарантии — задача в проекте объекта; раз в квартал РП смотрит, что повторяется, и правит шаблон |
| 5, 7. Сначала описать процессы, регламент без бюрократии | каркас `0010` + презентация | **берём**: после согласования с командой — регламент на 1–2 страницы «Как работаем в Битриксе» |
| 3. Воля руководителя | правило с 19.10 — оплата по безналу только по заявке | **берём**: первый месяц директор лично возвращает счета без заявки |
| 6. Не вводить дважды, источник — 1С | бухгалтер платит в 1С, в Битриксе ставит стадию; позже обмен | **подтверждает** приоритет обмена с 1С |
| 4. Мобильные заявки с объекта | форма для бригадира | **подтверждает** |
| 5. Не нагружать прораба кнопками | бригадир — только форма и фото в чат | **подтверждает** |
| 2. Контрольные точки | этапы графика, прогноз окончания | **подтверждает**. Критический путь не берём |
| 1. Стресс-бюджет, подушка в месяцах | нет | **берём вне Битрикса** — в работу по деньгам (`0002`, `0003`) |
| 3, 4. Лимит по смете, сметная цена против цены счёта, списание материала у подрядчика | бюджет по 4 статьям | **позже, если заболит**: когда материал наш и есть перерасход, добавить в заявку поле «сумма по смете» |

## Не берём

ERP за десятки миллионов, Power BI, UniFormat, проектное финансирование по
214-ФЗ, продажи и маркетинг застройщика, панель из 59 показателей, переход
к модели платформы. Всё это — уровень девелоперов, не нашего масштаба.
